Echo Notes

Final-year project

Formally AMTDS, an academic meeting transcription and document generation system. It records a meeting, separates the speakers, and turns the transcript into searchable notes. Students, supervisors, committees and admins each get their own access, enforced by row-level security in a 15-table Supabase database.
